# APIzzaParty

A PIzza Party is a fun single player game where you can play with different APIs. There is no particular winning/losing aspect of the game, it is just a compilation of short minigames. It consists of 5 main features: dog breed game guesser + pet (dog or cat), youtube view guesser, nationality guesser + corresponding portrait, age guesser, and a NASA space window. Each feature uses an API to get all of its data. In total it uses 8 different APIs: Zenserp, Random user, NASA, the CAT API, dog CEO, REST countries, nationalize, and agify. I utilized the HTTPS Requests features on Godot to call the api and request the different values, info, and images. 

It works perfectly well on godot however on itch sometimes the API images won't load. This game was made entirely on Godot by the way.
