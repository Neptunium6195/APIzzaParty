# APIzzaParty

A PIzza Party is a fun single player game where you can play with different APIs. It consists of 5 main features: dog breed game guesser + pet (dog or cat), youtube view guesser, nationality guesser + corresponding portrait, age guesser, and a NASA space window. In total it uses 8 different APIs: Zenserp, Random user, NASA, the CAT API, dog CEO, REST countries, nationalize, and agify. It works perfectly well on godot however on itch sometimes the API images won't load. This game was made entirely on Godot by the way.
